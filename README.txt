COVE CRICKET FANTASY — NEW UI
This fresh UI connects to the existing Supabase project.

Rules:
- Five club teams.
- Each team has 11 players.
- Editor chooses which teams play each week.
- Managers select exactly 2 players from each playing team.
- One real team captain is chosen as Fantasy Captain.
- A real captain selected only as a normal player gets NO winning bonus.
- A real captain selected as Fantasy Captain gets the winning bonus when their team wins.
- No captain double-points multiplier.
- One global leaderboard.
- Editor visibility is based on profiles.is_admin.

This build is the new UI/core selection foundation. Full persistent point entry, live leaderboard calculations, player history, and server-side validation still need to be completed.
The browser contains only the Supabase publishable key, not a service-role key.
